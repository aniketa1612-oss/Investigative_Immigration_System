# Architecture

Browser camera/microphone input begins only after explicit consent. The frontend records independent eight-second audio segments with `MediaRecorder`; FastAPI writes each segment to a temporary file, transcribes it with a locally stored faster-whisper model, and deletes the file immediately. The selected international language is passed as a Whisper language hint, while the detected language is returned for review. Transcript text is stored in SQLite.

MediaPipe vision WASM and the face-landmarker model are served from the frontend's local `public/models` folder. Neutral follow-up questions and reports are generated by local Ollama using `qwen3:14b`. REST handles lifecycle and records; SQLite supports local demonstrations and SQLAlchemy remains PostgreSQL-ready.

Raw audio/video persistence is off by default. Audio crosses only the localhost boundary for transcription and is removed after processing; video frames remain in the browser. Once dependencies, Whisper, MediaPipe, and Ollama models have been downloaded, the runtime has no internet dependency.
